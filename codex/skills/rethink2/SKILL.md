# Rethink2

ユーザーからの指示を受け、次の項目に答えられるように問題の解決策を検討してください。

- 問題とされる現象や目指す現象は具体的に何か
- 現在、周辺の課題や正常系ではどのようにタスクを解決しているか
  - どの要素が関わっているか
  - それぞれの要素の責務は何か
  - それぞれの要素の相互関係はどうなっているか
- 問題において満たすべき・破られた不変条件は何か、変わらず維持された不変条件は何か
- 不変条件が破られる直接理由は何か
- トレードオフ:
  - その不変条件を保証するべきなのはどの要素と考えられるか
  - その修正によってどのくらいの範囲の処理に影響が及ぶと考えられるか
