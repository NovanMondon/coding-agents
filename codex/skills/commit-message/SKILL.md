# Commit Message

ユーザーが行った変更に基づいて適切なコミットメッセージを生成します。

git の変更内容を調べ、適切なコミットについて考えてください。

- 変更の内容に未完のものがある場合、それをユーザーに通知し、特に指示がなければコミット対象から除外します。
- 変更に複数の内容が含まれる場合、それぞれの塊に応じて処理します。

その後、次をユーザーに伝えてください。コミットを複数に分割するべき場合は、それぞれについて提示してください。

- 適切なコミットメッセージ
  - 過去のメッセージの内容を参考にしてください。
- ステージング状態を適切に変更するためのコマンド

コミットをするべきでない内容がある場合は、それについてユーザーに通知してください。
