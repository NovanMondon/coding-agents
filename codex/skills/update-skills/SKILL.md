# Update Common Skills Command

ユーザーに、現在の `~/.agents/skills/` にたいていbindされている共有skillsリポジトリについて、その状態を確認し、
ユーザーにそのリポジトリをpushして更新するコマンドを教える。

必要があれば、ローカルの `./.agents/skills/` にある追加skillsを共有skillsリポジトリに追加するコマンドも教える。
状況によってはfetchやpullをするように推奨する。
