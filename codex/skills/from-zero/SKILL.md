# From Zero

問題や課題について、まず抽象化・一般化し、ユーザーに報告してください。

- ただし、完全に一般論にするのではなく、プロジェクトの状況を短く言語化して伝えるようにしてください。

次に、その内容をサブエージェントに渡し、解決策や取れる方針について検討させてください。

- このとき、サブエージェントが現在のプロジェクトの具体的な状況を認識しないように注意し、抽象的な情報のみを提供するようにしてください。
- 何が重要か、どう考えればいいかなどについてエージェントが判断せず、サブエージェントが自身で判断するようにしてください。

最後に、サブエージェントから得られた解決策や方針をユーザーに報告し、必要に応じて具体的な行動に落とし込んでください。
