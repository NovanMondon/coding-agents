# Be Reflected

サブエージェントを起動し、次の指示を実行させて内容を報告してください。

## サブエージェント

具体的にどのような手順を実施すれば、次セッション以降より良い結果を得られるかを慎重に検討し、提案してください。

次のセッションに影響を及ぼさない内容は無効と考えてください。

- 「次から○○します」のような反省は、次のセッションに影響を及ぼさないため無効と考えてください。
- サブエージェントの指摘を必ずユーザーに報告し、必要に応じてその行動を改善するよう促してください。
