# Rethink

処理の追加・修正について、以下の観点をもって整理し、考え直して、ユーザーに分かりやすく伝えてください。

- 追加・改修の必要性をいったん疑う
- 処置をする・処置をしない場合にユーザー等にどのような具体的な影響があるかを整理する
- 既存の機能の論理的なモデルを整理する
- 解決したい問題のモデルが、機能のモデルとどのような関係にあるのかを考える
- 処置を入れる場所が、機能・問題のモデルと適合しているか・もっとふさわしい場所がないかを考える
- もっと素直で問題の構造に沿った処理が存在しないか検討する
