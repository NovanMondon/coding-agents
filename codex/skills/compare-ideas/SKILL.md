# Compare Ideas

候補となっているアイデアを列挙し、サブエージェントによる盲検評価を行ってください。
コンテキストを共有しないサブエージェントにそれぞれのメリット・デメリットを評価させ、推奨される判断を提示させてください。
サブエージェントはコンテキストを読み取りにいかないでください。

自身でどちらを推奨するべきか判断しないでください。
どれかのアイデアが優れていると感じても、それがサブエージェントにとってわからないような文面を送ってください。
