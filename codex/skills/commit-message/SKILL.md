# Commit Message

ユーザーが行った変更に基づいて適切なコミットメッセージを生成します。

git の変更内容を調べ、適切なコミットメッセージを生成します。
既存のコミットメッセージもある程度参考にします。
その際、ステージングするべき変更とするべきでない変更・今コミットに入れるべき変更とあとにするべき変更の区別を考え、
現在のステージング状態と違いがある場合はユーザーにファイルパスを含めて報告し、適したファイルのみをステージングするコマンドを提案します。
必要に応じてパッチを作成することも考慮します。
