# Review Info

レビューに関する情報を、次の観点から示してください。
既存のレビューがある場合はそれについて、ない場合は1から調べて記述してください。
それぞれは3~20行程度で、言い換えや省略がなるべく無いように明確に記述してください。
ただし、内容がない場合は、無理に記述しないでください。

- 変更の目的・背景
  - ユーザーまたは開発者が問題に達するまでの経路を調べなおしてください。
  - なにかが拙い場合、どういう状況でなぜどのようにそれが問題であるかを具体的に記述してください。
- 変更の全体像
  - 変更全体の概要を簡潔に記述してください。
  - 変更されたファイルの一覧、変更の必要性、依存関係、変更内容とその意義を体系的に記述してください。
- 既存のレビュー内容
- 影響範囲とリスク
- 検証の状況
- 確認事項
